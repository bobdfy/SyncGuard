  • Save（L57-90）：与 synced_store 同款「整批事务 + pgx.Batch + ON CONFLICT (id) DO UPDATE」幂等 upsert；目标表约定 id TEXT PK / version INT / updated_at TIMESTAMPTZ / data JSONB。
  • 事务边界：Begin → SendBatch → 逐条 Exec → Close → Commit，defer Rollback 兜底，任一步错整批回滚。
  • 断点相关 4 方法空实现（L93-110）：外部 PG 不存断点，全部交 JobDestination。
  • Close（L46-51）：释放独立连接池，worker 用完必须 defer，否则每次外部同步泄漏一个池。
